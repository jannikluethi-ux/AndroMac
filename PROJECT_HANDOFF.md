# Project Handoff

## What success looks like

A user installs the application, connects an Android phone, unlocks it, chooses File Transfer if prompted, and sees the phone under Finder → Locations.

No custom file manager should be necessary for the core workflow.

## What not to optimize first

Do not start with:
- branding
- cloud sync
- wireless mode
- AI features
- media organization
- elaborate settings
- subscription infrastructure

The technical moat is reliability at the Finder/USB/Android boundary.

## First demo

Record a clean demo showing:
1. Finder open
2. Android phone not connected
3. USB connection
4. phone appears under Locations
5. DCIM opened
6. large file transferred to Mac
7. file transferred back to phone
8. cable removed
9. cable reconnected
10. Finder recovers automatically

This demo should be the project's first hard milestone.
